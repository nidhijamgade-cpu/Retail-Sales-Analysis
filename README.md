***🛍️ Retail Sales Analysis***

📌 Project Overview

This project focuses on analyzing retail sales data to identify sales trends, customer behavior, product performance, and overall business performance.

The project was completed using Excel, SQL, and Power BI, covering data analysis, data visualization, and dashboard creation.

🛠️ Tools & Technologies

- Excel – Data cleaning, analysis, Pivot Tables, and dashboard creation
- SQL – Data querying and business analysis
- Power BI – Interactive dashboard and data visualization

📊 Project Components

Excel

- Data analysis and preparation
- Pivot Tables and calculations
- Retail sales dashboard
- KPI analysis

SQL

- Data extraction and analysis
- Business-related queries
- Sales and customer analysis
- Aggregations and filtering

Power BI

- Interactive retail sales dashboard
- KPI visualization
- Sales performance analysis
- Charts and business insights
